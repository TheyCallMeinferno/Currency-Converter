# Currency Converter 💱

A simple and responsive Currency Converter web application built using **HTML, CSS, and JavaScript**.  
It fetches real-time exchange rates using the **Frankfurter API** and allows users to convert between supported currencies instantly.

---

## 🚀 Features

- 🌍 Real-time currency conversion
- 🔄 Swap between “From” and “To” currencies
- 🏳️ Country flags update dynamically
- ✅ Only supported currencies shown (no API errors)
- ❌ Graceful handling of unsupported conversions
- 📱 Responsive UI

---

## 🛠️ Tech Stack

- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript (ES6)** – Logic & DOM manipulation  
- **Fetch API** – API requests  
- **Frankfurter API** – Exchange rate data
